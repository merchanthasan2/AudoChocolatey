Catalog sources

Refresh the package catalog list when updates or search look stuck. Reset is recovery only — it restores the default WinGet sources.

Store app repair

Re-register a Microsoft Store app already installed for this Windows account. Use when a Store app will not open.

Duplicate files

Scan a folder for files that share size and contents. Recycle extra copies; one file in each group is always kept.

Orphan uninstallers

Remove Add/Remove Programs entries whose uninstall command is missing or points at a file that no longer exists. Then run a leftover scan.

Scheduled cleanup

Run selected cleanup categories on a daily or weekly schedule. The task runs Quantum Updater with no window.

Print queue

Cancel a stuck print job first. Clearing the whole queue stops the print spooler briefly and is recovery only.

Catalog export and import

Export installed WinGet app ids (with versions) to a JSON file, or import that file on another PC or after a reset. Save under your profile or Downloads only.

  • Export does not include installers — ids and versions only.
  • Import may download apps again and can take a long time.

App repair

Repair a WinGet desktop app when the publisher supports it. Reset removes a Store app's local data — load Store apps above, pick one in that list, then use Reset app data here.
