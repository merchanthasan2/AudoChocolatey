Hardware illustration library

Every drawing the live About this computer page can use, at 56 px (card size) and 160 px (hero size), in the normal theme (Direction B, left of each pair) and dark mode (Direction A, right). Same line style as the approved mockup: 2 px strokes, rounded caps, one accent fill, colours from --art-line, --art-accent, --art-fill. No logos are copied; a short text label on the filled plate carries vendor, family and generation. Source: parts.js (ADR 009).

How to use it

<script src="parts.js"></script>

// 1. Pick the drawing for a part (always returns a key that exists, falling back to the generic drawing for that kind)
const key = pickArt('cpu', { name: 'AMD Ryzen 7 4800H with Radeon Graphics' });   // 'cpu-amd-ryzen-7'
el.innerHTML = HARDWARE_ART[key];                                                  // sample text on the die

// 2. Or get the drawing with the REAL family and generation read from this PC
const { key, label, svg } = renderArt('cpu', { name: '13th Gen Intel(R) Core(TM) i7-13700H' });   // Core i7 / 13th Gen

// 3. Any family, any generation, from the template
makeCpuArt({ vendor: 'amd', family: 'Ryzen 7', generation: '4000' })
makeCpuArt({ vendor: 'qualcomm', family: 'X Elite', generation: 'X1E' })

/* Colours: set on any ancestor of the svg */
.art-host { --art-line:#6CD0EE; --art-accent:#FFD167; --art-fill:#06D7A0; --art-ink:#073A4B; }  /* ink = text on the fill, keep 4.5:1 */

makeCpuArt({ vendor, family, generation, ai, shape })

FieldValuesEffect
vendorintel amd qualcomm arm apple genericChooses the package shape: Intel is a square with a cut corner and heat-spreader line; AMD has pin fringe and a gold cut corner; Qualcomm is a rounded phone-style package with a stacked layer behind it; other ARM has a ring of ball dots; Apple is a rounded chip with two memory blocks beside it.
familytext, for example Core i7, Ryzen 7, Ultra 7, X Elite, M2First line on the die. Words inside it change the shape: Ultra splits the Intel die into two tiles, TR or Thread makes the wide Threadripper package, Athlon uses fewer pins, AI adds the sparkle.
generationtext, for example 13th Gen, 4000, Series 2, Pro, Gen 3Second line on the die (optional).
ai, shapeboolean, shape nameOptional overrides. Text is fitted to the die and never drawn smaller than 8 px at the 56 px size.

pickArt rules

Rules run top to bottom; the first match wins. Anything unmatched returns the generic drawing for that kind (shown in gold). Facts may also be passed as a plain string.

KindFacts readRules, in orderFallback
cpuname (processor brand string), optional arch
  1. Apple or M1-M9 alone: Pro/Max/Ultra word gives cpu-apple-pro|max|ultra, else cpu-apple-m1..m4, else cpu-apple-silicon
  2. Snapdragon / Qualcomm / X1E / X1P: X Elite, X Plus, 8cx, 7c, else cpu-snapdragon
  3. Intel: Core Ultra N (cpu-intel-ultra-5|7|9), Core iN (cpu-intel-core-i3|5|7|9), Celeron, Pentium, else cpu-intel
  4. AMD: Ryzen AI, Threadripper, Ryzen N (cpu-amd-ryzen-3|5|7|9), Athlon, else cpu-amd
  5. ARM words (Cortex, Neoverse, ...) or arch containing arm/aarch: cpu-arm
Generation: Intel from the leading "13th Gen" or the model digits (i7-13700H = 13th, i5-8250U = 8th, 3 digits = 1st); Core Ultra from the first model digit (155H = Series 1, 258V = Series 2); Ryzen from the first model digit (4800H = 4000); Snapdragon from "Gen n" or the X1E/X1P code.		cpu-generic
gpuname of each adapter
  1. Basic render, virtual, VMware, Hyper-V: gpu-generic
