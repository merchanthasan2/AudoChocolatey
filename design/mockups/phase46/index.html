What changes
  • Getting ready runs a full scan at every start (ADR 049, Q7). All checks run at the same time. The menu opens when the scan is done. Getting ready is not a menu item.
  • Sidebar: icons, a 3 px accent mark on the active item, an update count badge.
  • Sign-in is optional (Q1). "Not signed in · Sign in" sits at the bottom of the sidebar.
  • No "I confirm" tick box. One click for Update and Install. Remove, Update all and Update selected (2 or more apps) use a dialog (Q6). Update all dialog.
  • One activity bar at the bottom of every screen. One action runs at a time.
  • Friendly source names: Microsoft catalog, Microsoft Store, Installed directly.
  • Letter tiles in these mockups stand in for icons. The app must show each app's original icon on every screen (owner rule, ADR 049). A letter tile is the last resort only.
