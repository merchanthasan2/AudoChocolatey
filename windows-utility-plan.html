Recommended boundary

This app stays an updater plus trusted system tools. The matrix is a full Glary / CCleaner / PowerToys / DevToys / HWiNFO suite. Putting all 152 in this $100 product would stall the current System tools work and ship a kitchen sink.
Finish what is already building, then Wave 1. Cleanup safety, launch scans, About v2, Startup apps, Large files, leftover folders. Then complete Cleanup so Clean actually works with progress.
Windows-owned work goes through Windows. WinSxS, component cleanup, update cache, Defender, BitLocker keys, Store, WinRE. We orchestrate and confirm; we do not invent a second servicing stack.
Drivers, backup, and a vulnerability feed wait for licensing. That is already decided. They stay marked After licensing.
PowerToys-class tools become a later companion, not this app. Command palette, FancyZones, OCR, macros, DevToys, mouse-without-borders. Same company, different product, later.
We will not ship a registry cleaner, a dishonest wipe, partition recovery, or HDD defrag. Those either destroy disks or cannot keep the promise on an SSD.

Waves if you approve this boundary

Each wave is one tracker phase after the current System tools track. Mockups still come before layout changes. One owner decision at a time when a wave needs one.

Now — current track (do not pause). About v2, icons, cleanup safety, launch scans, Startup apps, Large files, leftover folders, real Optimize RAM.

Wave 5 — Files and admin. Checksums, empty folders, broken shortcuts, file lock, ZIP, ISO mount, services, optional features, keep-awake, Recycle Bin empty, removable-only format.
