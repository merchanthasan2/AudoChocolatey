# This branch

`channel/windows` is **DeskVerve for Windows**. Open `src\QuantumUpdater\bin\Release\net8.0-windows10.0.19041.0\win-x64\QuantumUpdater.exe` (the new WinUI app, Windows App SDK 1.8). It asks for admin each launch.

Mac work is on `channel/macos`; that later, separate product is **DeskVerve for Mac**. Do not copy Mac host code back onto this branch. The shared screens, colours, type, and brand stay here in `design/` and `brand/`.

Current artwork: `brand/desk-verve-emblem.png` is the transparent V-only master, `brand/desk-verve-icon.ico` is the Windows icon, and `brand/desk-verve-lockup-white.png` is the full lockup for light surfaces. Use only the transparent V on dark surfaces; never place the full black wordmark there.
