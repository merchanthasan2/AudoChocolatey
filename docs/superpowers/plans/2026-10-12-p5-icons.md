# P5 (pulled forward): Real, Original App Icons

> superpowers:executing-plans (Native). Test cases are the contract; Win32 extraction is verified live on the owner's PC.
> **Owner request (2026-10-12):** "Icons need to be actual original." Only icons that come from the app itself or its official publisher are used. Nothing is drawn or guessed.

**Goal:** Every app row shows its real icon. If no original icon can be found, the row keeps the neutral monogram tile. Icons are cached on disk, so they appear instantly and work offline.

**Architecture:**
- Rust `icons/` module behind a custom `icon` URI scheme (`http://icon.localhost/<key>?name=<display name>`). The CSP already allows `img-src http://icon.localhost`.
- The resolver tries original sources in order and caches PNG bytes under `%LOCALAPPDATA%\in.quantumstep.quantumupdater\icons\<sha256(key)>.png`. A miss is cached as `.miss` for 7 days.

**Original sources, in order:**
1. **Installed, registry `DisplayIcon`:** `path[,index]` (quotes stripped, env vars expanded). `.ico`/`.png` files are decoded directly; `.exe`/`.dll` go through `SHDefExtractIconW` at 128 px, then HICON to RGBA (`GetIconInfo`/`GetDIBits`; alpha rebuilt from the mask when needed), then PNG.
2. **Installed, `InstallLocation` with no icon:** the app's main `.exe`, searched to depth 2. Candidates are scored by name similarity; uninstallers, updaters and crash reporters are skipped.
3. **Installed MSIX (`MSIX\<PackageFullName>`):** `AppxManifest.xml` gives `<Logo>`, then the best `scale-*` variant under `Program Files\WindowsApps\<PackageFullName>`.
4. **Chocolatey package:** `IconUrl` (remembered from search, or OData `FindPackagesById`).
5. **winget package:** `winget show` gives the publisher **Homepage**. Its HTML (512 KB cap) is checked for `apple-touch-icon`, then the largest `rel=icon`, then `/favicon.ico`.

**Safety rules for remote icons:**
- https only; a 5 s timeout; at most 3 redirects; 1 MB cap; every resolved IP must be public (no loopback, private or link-local ranges).
- Every image is decoded and re-encoded to PNG: raster via `image`, SVG via `resvg`, with external references disabled.
- At most 4 remote fetches and 2 `winget show` calls at once.

## Review Focus
1. **A broken or hostile image** (truncated PNG, a zip bomb, a 50 MB response, SVG with external `href`) fails safely to the monogram and never crashes the app. Pinned in T2 (decode tests plus size cap).
2. **A homepage that redirects to http or a private IP** is refused. Pinned in T2 (`is_public_ip`, https-only client).
3. **Two rows asking for the same icon at once** cause one fetch, not two. Pinned in T3 (in-flight dedupe test).
4. **Registry entries without DisplayIcon** still find the main exe while skipping `unins000.exe` and `Update.exe`. Pinned in T1 (`choose_exe`).
5. **Offline:** cached icons still show, and misses don't retry for 7 days. Pinned in T3.

### T1: Pure helpers
`icons/sources.rs`:
- `parse_display_icon("\"C:\\a\\b.exe\",0")` gives `(C:\a\b.exe, 0)`. `"C:\\x.ico"` gives `(…, 0)`. `"C:\\y.exe,-101"` gives index −101.
- `choose_exe(["unins000.exe", "Update.exe", "Discord.exe", "crashpad_handler.exe"], "Discord")` gives `Discord.exe`. `choose_exe(["Acrobat.exe", "AcroCEF.exe"], "Adobe Acrobat (64-bit)")` gives `Acrobat.exe`.
- `name_matches("CrystalDiskInfo 9.9.2", "CrystalDiskInfo 9.9.3")` is true (trailing versions ignored); `("Git", "GitHub CLI")` is false.
- `pick_icon_link(html, base)` prefers apple-touch-icon over the largest `sizes` icon over the first icon; resolves relative URLs; skips `data:` and `http:`.
- `msix_logo(manifest_xml)` returns the `<Logo>` path.

### T2: Safe fetch and normalize
`icons/image.rs`: `to_png(bytes, max=128) -> AppResult<Vec<u8>>` for PNG, ICO, JPEG, WebP and SVG fixtures. Truncated input gives Err. SVG with an external image reference renders without fetching it.
`icons/fetch.rs`: `is_public_ip` for 127.0.0.1, 10.x, 192.168.x, 169.254.x, ::1 and fc00:: (all false) and 1.1.1.1 (true). The size cap stops at 1 MB plus 1 byte.

### T3: Resolver, cache and protocol
`icons/mod.rs`: `IconService::resolve(key, name) -> Option<Vec<u8>>`.
- Disk cache hit: no work is done.
- A miss file younger than 7 days returns `None` immediately.
- Concurrent requests for one key share a single resolution (`tokio::sync::OnceCell` per key).
- Live: Git (`.ico`), VS Code (`.exe`) and CrystalDiskInfo (`.exe`) give PNG with width at least 32.

Protocol: `register_asynchronous_uri_scheme_protocol("icon", …)`. It responds 200 `image/png` with `Cache-Control: max-age=604800`, or 404.

### T4: Wire into the UI
- `iconKey` on Updates, Installed, the Marketplace grid and search rows (`<source>:<id>`, or `local:<id>` with `name`).
- Choco search results seed `IconUrl` into the service.
- Screenshot check: real icons in all views, light and dark.
