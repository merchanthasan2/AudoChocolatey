# P1: Rust Core and Package Sources Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans (owner chose Native execution for the whole programme). Steps use checkbox (`- [ ]`) syntax.
>
> **Format note:** the planner and the executor are the same session. Each task lists its test cases as exact inputs and expected outputs, and those cases are the contract. Implementation code is written under TDD at execution time instead of being duplicated here. Interfaces are exact.

**Goal:** Talk to winget and Chocolatey safely and correctly: validated IDs, no shell, locale- and width-safe parsing of real output, Rust-owned settings. Expose the first real commands (`get_overview`, `get_diagnostics`, `list_installed`, `list_updates`, `search`, `get_settings`, `update_settings`) with ts-rs-generated TypeScript types.

**Architecture:**
- `sources/process.rs` is the only process spawner (absolute exe, argv, `CREATE_NO_WINDOW`, timeout).
- A `Runner` trait sits behind it, so the sources can be fed fixture text in tests.
- `WingetSource` and `ChocoSource` implement `PackageSource` (async-trait).
- Commands aggregate both sources unmerged and return per-source errors without failing the whole call. P2 adds merging.
- Settings is a Rust-owned JSON file with atomic writes and versioned migration.

**Tech Stack:** Rust 2021, tokio (process, time), async-trait 0.1, regex 1, unicode-width 0.2, reqwest 0.13 (rustls, no default features), quick-xml 0.42, ts-rs 12, tempfile 3 (dev).

**Spec:** [docs/superpowers/specs/2026-10-12-quantum-updater-v3-redesign-design.md](../specs/2026-10-12-quantum-updater-v3-redesign-design.md) §5.2, §5.3, §5.7, §6, §8, §10

## Facts from real output on the owner's PC (winget 1.29.380, choco 2.7.4)
These override spec assumptions:
- **No truncation when piped.** Piped winget output pads columns to the longest value; no `…` appears. The truncation fallback is kept but is secondary.
- **Single-space header gaps.** Headers can be separated by a single space (`Version Available Source`). Column starts must be the start offsets of the header tokens, not 2+ space gaps.
- **Local-only rows.** `winget list` includes rows with an empty Source and IDs like `ARP\Machine\X64\Android Studio`, `MSIX\…_x64__…`. These are display-only, never `WingetId`.
- **Search includes msstore rows** unless `--source winget` is passed.
- **Footer lines** (`1 upgrades available.`, long "cannot be determined" sentences) and a second "explicit targeting" table can follow the first table.
- **Non-elevated choco prints retry noise** (`This is try 1/3…`, `Access to the path … denied`) mixed into `-r` output.
- **Chocolatey OData `Search()` returns several versions per package.** Use `$filter=IsLatestVersion`, and dedupe by Id (the Id is the entry `<title>`).

## Global Constraints
- Spec §8 validation:
  - WingetId `^[A-Za-z0-9][A-Za-z0-9.+_\-]{0,127}$`
  - ChocoId `^[A-Za-z0-9][A-Za-z0-9._\-]{0,99}$`
  - Version `^[A-Za-z0-9][A-Za-z0-9.+_\-]{0,63}$`
  - Search query: 1–100 chars after trim, control chars stripped, no leading `-`.
- Never `--force`, never `--all`. Winget package ops always use `--exact --id <id>`; install and upgrade also use `--source winget`.
- Exclude `QuantumStep.QuantumUpdater` from update lists.
- Executables:
  - winget: `%LOCALAPPDATA%\Microsoft\WindowsApps\winget.exe`
  - choco: `%ChocolateyInstall%\bin\choco.exe`, falling back to `%ProgramData%\chocolatey\bin\choco.exe`
  - Never looked up via PATH.
- Every new command goes in `build.rs` `COMMANDS` plus `capabilities/main.json` (`allow-<kebab>`) plus `app/src/lib/ipc/commands.ts`.
- IPC types are serde camelCase; enums are lowercase strings.
- The PLAN.md checkbox is ticked in the same commit as each task.

## Review Focus
1. **A machine with Chocolatey not installed** (the default for most users): `get_overview` shows choco `missing`, and `list_installed`/`list_updates`/`search` still return winget results with no error banner. Pinned in T7 (fake runner returns NotFound for choco).
2. **winget prints no table** (no updates, or no search results with exit code `0x8A150014`): the result is an empty list, not an error. Pinned in T4.
3. **A footer sentence long enough to cross column boundaries** must not become a fake package row. Pinned in T4 (the `list.en.txt` row count equals the real count).
4. **Settings file from a newer app version, or corrupt JSON:** the app still starts with defaults and never overwrites the newer file. Pinned in T6.
5. **IDs with `+` (`Notepad++.Notepad++`) and choco IDs with dots (`visualstudio2022-workload-vctools`, `chocolatey-core.extension`)** validate. Injection-shaped input (`-y`, `a b`, `x;calc`, `--source=evil`, unicode) is rejected. Pinned in T1.

### Task 1: Core types (error, ids, versions)
**Files:** Create `src-tauri/src/error.rs`, `src-tauri/src/ids.rs`, `src-tauri/src/versions.rs`. Modify `src-tauri/src/lib.rs` (mod decls) and `Cargo.toml` (regex, ts-rs).

**Interfaces (Produces):**
- `AppError { code: String, message: String }`: `Serialize`, `TS`. Constructors: `AppError::new(code: &str, msg: impl Into<String>)`; `impl From<std::io::Error>`. Codes: `invalid_input`, `source_missing`, `process_failed`, `timeout`, `parse`, `network`, `settings`.
- `type AppResult<T> = Result<T, AppError>`.
- `SourceKind { Winget, Choco }`: serde lowercase, `TS`, `Copy`, `Eq`, `Hash`.
- `WingetId`, `ChocoId`, `PkgVersion`: newtypes over `String` with `TryFrom<String>` (error `AppError invalid_input`), serde `try_from = "String"` / `into = "String"`, `as_str()`, `TS` as `string`.
- `SourceRef { source: SourceKind, id: String }`, validated at deserialize: the id must pass the validator for its `source`. Method `SourceRef::new(source, id) -> AppResult<SourceRef>`.
- `SearchQuery(String)`: `TryFrom<String>` trims, strips control chars, length 1..=100 chars, rejects a leading `-`.
- `versions::compare(a: &str, b: &str) -> std::cmp::Ordering`.

**Test cases (write first, watch fail):**
- WingetId accepts: `Mozilla.Firefox`, `Notepad++.Notepad++`, `CrystalDewWorld.CrystalDiskInfo`, `7zip.7zip`, `Microsoft.VCRedist.2015+.x64`.
- WingetId rejects: `""`, `-y`, `--source=evil`, `a b`, `x;calc`, `ARP\Machine\X64\Android Studio`, `Mozilla.Firefox…`, `Ｆirefox`, and a 129-char id.
- ChocoId accepts: `vscode`, `chocolatey-core.extension`, `visualstudio2022-workload-vctools`, `KB2919355`. Rejects: `-y`, `a+b`, `a b`.
- PkgVersion accepts: `1.95.2`, `0.0.311`, `117.14.19`, `2.0.0-beta+1`. Rejects: `-1`, `1 2`, `""`.
- SourceRef JSON `{"source":"winget","id":"Notepad++.Notepad++"}` deserializes. `{"source":"choco","id":"Notepad++.Notepad++"}` fails (`+` is invalid for choco). `{"source":"winget","id":"-x"}` fails.
- SearchQuery: `"  firefox "` becomes `firefox`; `"fire\u{0007}fox"` becomes `firefox`; `""`/`"   "` are rejected; `"-y"` is rejected; a 101-char query is rejected; `"visual studio"` is accepted.
- versions::compare: `1.95.2 < 1.95.10`; `9.9.2 < 9.9.3`; `1.0 == 1.0.0`; `2.0.0-beta < 2.0.0`; `117.14.19 < 117.14.41`; `26.002.21931 > 26.1.0`; `0.0.309 < 0.0.311`.
  - Algorithm: split on `[.\-+_]`; compare segments numerically when both are digits, otherwise lexically (case-insensitive); missing segments count as 0, but a trailing alphabetic pre-release segment sorts below an absent one.
- AppError serializes as `{"code":"invalid_input","message":"…"}`.

Commit: `feat(core): validated id newtypes, AppError and loose version compare`

**Test cases:**
- `strip_ansi("\x1b[32mok\x1b[0m")` returns `ok`.
- `resolve_winget`: with `LOCALAPPDATA=C:\U\AppData\Local`, the existing exe gives `C:\U\AppData\Local\Microsoft\WindowsApps\winget.exe`. A missing exe gives `None`. A missing env var gives `None`.

### Task 4: winget source (parser, argv, source impl)
**Files:** Create `src-tauri/src/sources/winget/{mod,parse,args}.rs`, `src-tauri/src/sources/model.rs`. Add unicode-width.

**Interfaces (Produces), in `sources/model.rs`, all `Serialize` + `TS`, camelCase:**
- `InstalledPackage { name, id: String, version: String, available: Option<String>, source: Option<SourceKind> }`. `source` is `None` for local-only rows.
- `UpgradeCandidate { name, id: String, installedVersion: String, availableVersion: String, source: SourceKind }`
- `SourcePackage { name, id: String, version: Option<String>, source: SourceKind, matchedOn: Option<String>, description: Option<String>, homepage: Option<String>, iconUrl: Option<String> }`
- `SourceState`, a tagged enum serialized as `{"state":"ready","version":"1.29.380"} | {"state":"missing"} | {"state":"broken","reason":"…"}`. `SourceStatus { kind: SourceKind, #[serde(flatten)] state: SourceState }`.
- `OpKind { Install, Upgrade, Uninstall }` and `OpRequest { kind: OpKind, target: SourceRef, version: Option<PkgVersion> }`.

**`parse::Table` / `parse_tables(stdout: &str) -> Vec<Vec<Vec<String>>>`** (tables, then rows, then cells):
- Normalize each line: keep the text after the last `\r`, strip ANSI, trim the end.
- A table starts at a line made only of `-` (length ≥ 10); the header is the previous non-empty line.
- Column starts are the display-width offsets of each whitespace-separated header token.
- A row is accepted while it is non-empty and every column start ≤ its width has a space at display offset start−1 (or the start is beyond the line end, which means an empty cell).
- The first rejected or empty line ends the table; scanning resumes for the next separator.
- Cells are sliced by display width and trimmed.

**Column mapping (position-based, locale-agnostic):** col0 = name, col1 = id, col2 = version. If there are 5 columns, col3 = available/match and col4 = source. If there are 4, col3 = source.

**`WingetSource<R: Runner>`:**
- `status()`: `winget --version`, strip the leading `v`.
- `list_installed()`: `list --accept-source-agreements --disable-interactivity`.
- `list_upgrades(include_unknown)`: `upgrade [--include-unknown] --accept-source-agreements --disable-interactivity`. Keep only rows with source `winget` and a valid WingetId; drop the self ID.
- `search(q)`: `search --query <q> --source winget --count 50 --accept-source-agreements --disable-interactivity`.
- **No table** gives an empty Vec when the exit code is 0 or `-1978335212` (`0x8A150014`); otherwise `process_failed` with the last 300 chars of output.
- **Truncated IDs** (ending in `…`): in list/upgrade, resolve through one `winget export -o <temp> --include-versions` by unique prefix, otherwise drop the row; in search, drop the row.

**`args::build_op(op: &OpRequest) -> Vec<String>`:**
- install/upgrade: `[kind, "--id", id, "--exact", "--source", "winget", "--silent", "--disable-interactivity", "--accept-package-agreements", "--accept-source-agreements"]` plus `["--version", v]`.
- uninstall: `["uninstall", "--id", id, "--exact", "--silent", "--disable-interactivity", "--accept-source-agreements"]`.

**Test cases (fixture-driven, FakeRunner returning fixture text):**
- `upgrade.en.txt` gives exactly 1 candidate: CrystalDiskInfo 9.9.2 → 9.9.3, source winget, name `CrystalDiskInfo 9.9.2`.
- `upgrade-explicit.en.txt` gives 3 candidates: `Microsoft.VisualStudioCode`, `Discord.Discord`, `Microsoft.WSL`.
- `upgrade.de.txt` and `upgrade.ja.txt`:
  - same candidates as their English counterparts;
  - the Japanese name `メモ帳++` comes through intact;
  - no panic.
- `upgrade-truncated.en.txt` plus export JSON with `Contoso.VeryLongPackageName` resolves the truncated ID. An unmatched prefix drops the row.
- `list.en.txt`:
  - row count equals `grep -c` of data lines (computed in the test as lines between the separator and the first line that fails the boundary rule);
  - `Adobe.Acrobat.Pro` has source winget;
  - `ARP\Machine\X64\Android Studio` has source `None` and keeps the spaces in its id;
  - no row's name starts with a digit followed by ` upgrades`.
- `list-spinner.en.txt` parses the same as without the spinner.
- `search-firefox.en.txt`: the first row is id `Mozilla.Firefox`, `matchedOn` `Moniker: firefox`, version `157.0.1`; every row has source winget.
- `search-code.en.txt` (captured without `--source`): msstore rows are excluded.
- `no-results.en.txt` with code −1978335212 gives `Ok(vec![])`. Same text with code 1 gives `Err(process_failed)`.
- An upgrade row with id `QuantumStep.QuantumUpdater` is excluded.
- `build_op`:
  - install with version gives the exact argv above;
  - no element equals `--force` or `--all`, for every OpKind;
  - the id is its own argv element even with `+`.

Commit: `feat(winget): locale-agnostic table parser, safe argv builder and winget source`

### Task 5: Chocolatey source
**Files:** Create `src-tauri/src/sources/choco/{mod,parse,args,odata}.rs`. Add reqwest (`rustls-tls`, `http2`, no default features) and quick-xml.

**Interfaces:**
- `ChocoSource<R: Runner>` with:
  - `status()`: `choco --version`; non-zero exit gives `Broken`; exe absent gives `Missing`;
  - `major_version()`;
  - `list_installed()`: v2 `list -r`, v1 `list --local-only -r`;
  - `list_upgrades()`: `outdated -r`;
  - `search(q)` via OData.
- `parse::pipe_rows(stdout, min_fields) -> Vec<Vec<String>>`: only lines matching `^[A-Za-z0-9][A-Za-z0-9._\-]*\|`, split on `|`, with at least `min_fields` fields.
- `odata::search_url(q: &SearchQuery) -> String`: `https://community.chocolatey.org/api/v2/Search()?searchTerm='<q with ' doubled, URL-encoded>'&targetFramework=''&includePrerelease=false&$filter=IsLatestVersion&$top=30`.
- `odata::parse_feed(xml: &str) -> AppResult<Vec<SourcePackage>>`:
  - id from the entry `<title>`, plus `d:Version`, `d:Title` (display name), `d:Description` (plain text, at most 400 chars), `d:ProjectUrl` (homepage, https only) and `d:IconUrl` (https only);
  - deduped by id, preferring `d:IsLatestVersion=true`.
- HTTP: 10 s timeout, user-agent `QuantumUpdater/<version>`, https only.
- `args::build_op(op)`:
  - install: `["install", id, "-y", "--no-color"]`; upgrade: `["upgrade", id, "-y", "--no-color"]`; both take `["--version", v]` when a version is given;
  - uninstall: `["uninstall", id, "-y", "--no-color"]`.

**Test cases:**
- `list-r.v2.txt` (with retry noise) gives 16 packages. The first is `chocolatey` 2.7.4. No row contains `try` or `Access`.
- `outdated-r.v2.txt` gives 3 candidates, including `vcredist140` 14.44.35211 → 14.51.36247.
- Version text `2.7.4` gives major 2, so the list args are `["list","-r"]`. `1.4.0` gives `["list","--local-only","-r"]`.
- `odata-search-firefox.xml` gives exactly one `Firefox` entry with display name `Mozilla Firefox`, version `141.0.0`, an `iconUrl` beginning `https://cdn.jsdelivr.net/`, and a non-empty description with no `<` characters.
- `search_url` for `o'neil` contains `searchTerm='o''neil'` (URL-encoded) and `$filter=IsLatestVersion`.
- `build_op` never contains `--force`, the id is its own element, and the version is appended.
- Status when the runner returns `source_missing` gives `{"state":"missing"}`.

### Task 6: Settings store
**Files:** Create `src-tauri/src/settings/{mod,schema}.rs`. Add tempfile (dev).

**Interfaces:**
- `Settings` (serde camelCase, `TS`) matching spec §5.7 schema v1:
  - `schemaVersion: 1`, `theme: "system"|"light"|"dark"`, `motion: "system"|"reduced"|"full"`;
  - `checkIntervalHours: u32` (default 6, allowed 1..=168);
  - `notifyUpdates`, `startAtLogin`, `startInTray`, `closeToTray` (all true), `showUnknownVersions` (false);
  - `selfUpdate: "notify"|"auto"|"off"`, `choco: { enabled: true, bootstrapPrompted: false }`, `lastCheckAt: Option<String>`.
- `SettingsPatch`: every field optional (`TS`).
- `SettingsStore::open(path) -> SettingsStore`, which never fails, plus `get() -> Settings`, `apply(patch) -> AppResult<Settings>`, and `read_only() -> bool`.
- Writes are atomic: write `settings.json.tmp`, flush, then `std::fs::rename` over the target.

**Test cases (tempdir):**
- A missing file gives defaults, and the file is created on the first `apply`.
- A round trip of `apply({theme:"dark"})` then reopen gives `theme == dark`.
- `checkIntervalHours: 0` and `200` give `invalid_input`, and the file is unchanged.
- Corrupt JSON gives defaults; the original file is renamed to `settings.json.bak`; the store is not read-only.
- `{"schemaVersion": 99, …}` gives defaults with `read_only() == true`; `apply` returns a `settings` error; the file bytes are unchanged.
- A file missing fields (`{"schemaVersion":1,"theme":"light"}`) loads with defaults filled in and `theme == light`.
- No `.tmp` file remains after a successful write.

Commit: `feat(settings): Rust-owned settings with atomic writes, migration guard and validation`
