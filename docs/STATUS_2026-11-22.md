## Security fix for 49.1 (done in 6eba13c)

`StartWithWindowsService.RegisterTask` writes the task XML to `%TEMP%` and then runs elevated `schtasks /Create /XML`. A non-elevated process could swap the file in between and get an admin logon task (a UAC bypass). The fix is to register through the Task Scheduler COM API (`Schedule.Service`) with the XML as a string and no file.
